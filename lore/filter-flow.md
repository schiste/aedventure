# How the Filter formed

The Filter was an unintended cascade in the satellite repair network. This sequence follows the canon in [The Truth](the-truth.md) and the [documented timeline](timeline_events.md).

The dampening field suppressed most airborne sound. That silence removed the vibration that kept Hush-2 dormant, starting the separate biological crisis. The network failure created the conditions for that crisis; the virus caused the first wave of deaths.
