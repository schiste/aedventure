# Structured data

- `calendar.json`: shared AS/CE anchors.
- `entities.json`: people, places, factions and survival groups.
- `events.json`: reusable dated events.
- `claims.json`: sourced assertions with status.
- `relations.json`: typed relationships for the graph view.
- `sources.json`: provenance registry.
- `survival_rules.json`: shared survival windows and time conversions, with sources and mechanical references.
- `population_model.json`: draft population checkpoints and demographic inputs requiring validation.
- `regional_survivor_model.json`: draft spatial survivor model for Paris and a 1,000 km radius.
- `population_approximation_model.json`: lightweight macro-zone approximation for population allocation without a large raster.
- `macro_zones_paris_1000km.json`: draft calculation units for the Paris 1,000 km study area.
- `macro_population_envelope.json`: coarse 2024 population envelope before spatial and demographic recalibration.
- `refuge_evidence.json`: sourced evidence and explicit unknowns for shelters and preparedness.

Markdown remains the editorial source. These records drive indexes, cards,
timeline, graph and map views. They do not silently promote draft material to
canon.
